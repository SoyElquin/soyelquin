# Elquin Hernández — Portafolio personal

Proyecto Next.js para el portafolio personal de Elquin Hernández Buelvas, productor audiovisual y estratega de marketing.

## Enfoque

El sitio funciona como una hoja de vida visual: presenta perfil, experiencia, servicios, proceso, videos publicados, herramientas, empresas vinculadas, referencias personales y contacto.

## Cambios de la versión v7

- Hero corregido para que el título principal sea Elquin Hernández.
- Eliminación de textos que explicaban decisiones de diseño.
- Referencias reescritas con empresas y contactos proporcionados.
- Eliminación del bloque de avatar personal innecesario en referencias.
- Favicon generado desde my-avatar-2.
- Imagen Open Graph reemplazada sin texto encima del rostro.
- Ajustes de tipografía, jerarquía y responsive para reducir saturación.

## Comandos

```bash
npm install
npm run dev
npm run quality
```
